# RedPilot｜薯航

自用小红书内容运营工作台。独立仓库，公开托管。

## 启动

需要 **Node.js 22.18+**，无 npm 运行依赖。首次使用先在本机配置登录账号：

```bash
npm run auth:configure
```

按提示输入登录邮箱和密码，密码不回显。再启动服务：

```bash
npm start
```

打开 **http://localhost:4317**。开发时运行 `npm run dev`。修改端口可在 `.env` 中设置 `PORT`。当前工作站使用本机端口 **4319**，尚未公网部署；默认启动命令与默认端口不变。

## 当前可用

- 平台登录：固定单用户邮箱与密码、默认记住登录30天（可取消）、退出登录、服务端保护全部业务接口和素材。
- 热点跳转：点击榜单词条或平台标签，在新标签页打开对应平台的关键词搜索；推荐词条优先使用当前有效来源，原始出处仍保留用于收藏和创作。
- 操作归位：无来源的新建草稿只在创作工作台；账号连接通过左下菜单的账号资料弹窗检查，每日发布从同一菜单直接打开。单账号不显示多余选择器，统计不附定义说明，正常连接和运行细节按需查看。
- 界面文案只保留字段名称、操作和必要状态；换行、分隔、保存影响等规则由系统处理，不作为常驻教学说明。异常时再显示具体纠正提示。
- 蓝白简约界面：今日工作台、灵感收集、创作工作台、发布排期、产品资料。左下角账号菜单统一提供切换、添加、账号资料、每日发布与退出登录，没有独立账号管理页面。热点与关注博主放在灵感收集内，配图直接放在稿件编辑器旁。
- 多账号工作区：切换账号后，收藏、关注博主、草稿、配图、排期、日报、产品资料、素材和飞书来源整体切换；内置发布驱动当前共用单个 Chrome 登录态。
- 草稿和任务绑定账号，发布前固定外部账号 ID；回执必须匹配同一账号。
- 收藏只需粘贴笔记、账号链接或分享内容；后台通过已连接 Chrome 自动补齐标题、正文、作者、话题和图片。
- 截图分组上传和手动正文作为可选补充，按笔记 ID、图片 SHA-256 合并重复资料。
- 收藏标签、参考详情和删除；每条收藏可勾选“用于每日自动创作”，热点选题也存入同一收藏列表。
- 关注博主：主页或小红书号添加、每日同步近期笔记、按笔记 ID 去重，可单独开启 AI 自动拆解。
- 七平台官方榜单并列展示，按账号方向进行可解释的规则匹配；可直接收藏或生成草稿，保留来源。
- 每账号运营日报：待办计划、当天可验证发现、来源与缺口；保留09:00自动生成和历史日期查看。
- 产品介绍、卖点与来源编辑；页面不展示内部使用条件、未验证承诺等规则栏目。
- 飞书资料按需手动同步；在产品资料的资料来源旁点击“飞书同步”刷新，保留来源快照及读取状态。
- 产品素材库：图标、产品图片、宣传册、模型上传与已有本地模型引用，真实预览与下载、SHA-256 去重。
- STEP 模型按标准、正面、侧角渲染，生成 1200 × 1600 PNG 自动回存素材库。
- 文字稿与图文稿分别生成、编辑、审核与排期；本地事实模板可离线使用。
- 文字稿预览与导出文案；内置 Chrome 通道的原生文字配图目前为 `unsupported`，不能实际提交。
- AI 图文稿先生成文案，再自动制作本篇封面和内页；产品原图作为外观参考。可预览和导出选定成品，图标另附在 ZIP 的 sources/。新草稿不生成辅助分镜或固定栏目，旧值仅保留存储兼容，不显示、不参与发布检查或导出包。
- 编辑停止900ms后自动保存，服务端核对草稿版本；“确认并排期”一次完成归属账号核对、内容检查、批准和未来时间排期，仍可取消任务、查看运行日志。
- AI 修改会生成独立改写稿，保留原稿；完成通知仅提示一次，后台任务历史继续保存。
- 每日生成调度、内置 Chrome 图文驱动、外部发布桥 v3、持久化幂等记录与只读结果核对；真实图片提交尚未实测。
- 服务连接在后台保留；页面不展示密钥、模型或连接配置表单。账号登录检查保留在账号资料弹窗，首篇发布仍需在排期前确认内容。
- 本机 JSON 持久化与数据快照导出。

## 需要配置的功能

AI 使用后台已保存的连接配置；部署时的环境配置可从 `.env.example` 开始。公开状态与 GET 接口不返回密钥或尾部掩码。

| 功能 | 配置与边界 |
| --- | --- |
| AI 截图分析、参考改写 | 后台配置支持 Chat Completions 与 Responses。连接验证与实际生成分别记录结果。实际创作会向所配服务发送选中参考与产品资料。 |
| 图片生成、参考图编辑 | 可设置 `REDPILOT_IMAGE_API_KEY`、图片服务地址和模型；图片与文字服务地址一致时，可复用主 AI 密钥。实际生图能力需由图片任务验证。 |
| 实际小红书发布 | 已实现内置 Chrome 图文驱动与严格账号连接检查，并保留 [外部发布桥 v3](docs/publishing-bridge.md)。当前只实网核验了只读身份链；图片上传、填充与点击发布均未实测，首篇发布尚未验证。 |
| 每日任务 | 每账号设置时间、IANA 时区、自动/审核模式与图文比例，默认图文70%/文字30%，各账号默认关闭，每天一次。按成功生成数均匀轮换，失败与手动生成不占比；改变比例重新计数，保留历史。服务关闭或电脑休眠时不执行，不补往日内容。 |
| 登录掉线提醒 | 默认每天北京时间08:00检查启用且已连接的账号。确认掉线或登录身份不符时通过公司飞书应用私信提醒；同一次掉线只通知一次，恢复后重置。读取失败不判为掉线。服务需运行；当天08:00后启动会补查一次，不补查往日。 |
| 飞书资料 | 点击“飞书同步”才读取资料，不在后台定时同步；依赖本机 Chrome 登录和文档权限。读取目录/文档可见正文，保留完整度及旧快照，不自动覆盖手工产品事实。 |
| 链接读取 | 使用本机 Chrome 的已授权读取桥，默认 `http://127.0.0.1:3456`，可设 `REDPILOT_READER_PROXY_URL`；当前工作站已连接。仅自动读取小红书笔记、主页与官方分享短链，不需要文字 AI 密钥。需要 Chrome 登录或验证时保留收藏并显示原因，处理后可重读。 |
| 博主同步与自动拆解 | 同步使用已连接、已登录小红书的 Chrome；每个博主单独设置同步时间和时区。自动拆解默认关闭，需要开启并另行配置文字 AI；未配置时正常同步入库，拆解保留待处理。 |
| 热点与运营日报 | 采集只用官方网页或公开官方接口；部分站点需要已连接 Chrome 的登录状态。榜单匹配和日报使用本地规则，不依赖 AI。每个启用账号的日报固定每日09:00、Asia/Shanghai自动生成，无需设置；服务关闭或休眠时不执行。 |

未配置 AI 时可使用本地事实模板。模板不会识别截图、执行自由改写或迁移参考风格，页面会明确标注。AI 分析输出经过格式校验，仍需核对事实；基础检查不是完整的宣传事实审核。

各账号的自动模式会从勾选“用于每日自动创作”的收藏中选择使用次数较少、且该账号可使用的参考，生成内容，通过基础检查后交给所选发布通道。内置 Chrome 首篇必须由用户确认并排期；自动生成稿会阻塞，不能代替这次人工核对。只有同一账号取得真实已发布笔记的核验记录后，才开放自动发布通道。生成失败或资料缺失时记录原因；当前未实现多候选逐个回退和语义去重，仅检查该账号的重复标题。审核模式只生成草稿，人工确认后自行安排发布时间。

## 工作区导航

| 入口 | 功能 |
| --- | --- |
| 今日工作台 | 运营概况、当日日报与历史日报、优先待办和来源发现 |
| 灵感收集 | 统一收藏、热点、关注博主；逐条选择是否用于每日自动创作 |
| 创作工作台 | 同篇文案编辑、自动配图、单图修改与预览排期 |
| 发布排期 | 月历查看当前账号的安排，按日期查看任务封面、时间、状态及历史记录 |
| 左下账号菜单 | 切换和添加账号、账号资料、每日发布、飞书提醒、退出登录 |
| 产品资料 | 产品事实、飞书同步、图片与3D素材 |

旧的 `#trends`、`#creators`、`#images`、`#calendar` 链接继续有效；草稿与参考的深层链接仍能定位原内容。独立讨论界面已移除，历史讨论记录及兼容接口保留；旧讨论链接优先打开关联草稿，没有关联草稿时进入创作工作台。

发布排期的月历和发布时间输入统一使用北京时间，周一为每周首日。点击日期查看当天任务，可翻月或返回今天；已取消任务保留在当天记录中，不计入月历排期数。日报的发布入口和新保存的排期会定位到对应日期，账号切换后重新显示该账号的安排。查看草稿、取消、重试、核对发布结果沿用原操作。

界面使用统一的 rem 字号变量：正文、表单和导航默认 16px，按钮 15px，辅助信息 14px，数字徽标 13px；卡片、区块、页面标题分别为 18、20、28px（手机页面标题 24px）。正文行高 1.65，常规按钮至少 44px 高，输入框至少 48px 高。窄屏通过折行、单列和横向导航适配，保留可读字号。字号层级参考 [Ant Design](https://ant.design/docs/spec/font/) 与 [IBM Carbon](https://www.carbondesignsystem.com/building-blocks/foundations/typography/type-sets)，针对个人使用与中文阅读采用 16px 正文。

## 灵感到草稿

收藏入口只需粘贴链接或上传截图，可选填一句创作要求；可直接“收藏并生成”，也可“仅收藏”。链接读取后自动补齐内容，再接续生成，不要求先手动分析。已收藏内容可一键生成，默认使用所选账号、图文方式、已配置 AI 及产品图片；生成方式、借鉴方式等选项折叠在高级设置中。接口测试素材、模型预览及其调整结果不能作为发布配图；草稿专属封面不自动用于下一篇内容。

收藏列表不再按“已分析/待分析”分类；拆解不是创作的前置步骤。关注博主的后台自动拆解仍可启用，已有结果可在收藏详情的“查看拆解 · 高级”查看。

创作工作台默认展示当前账号的草稿列表，卡片包含封面、标题、更新时间和状态，可搜索标题及正文，按草稿、已排期、已发布筛选。点击稿件进入独立编辑页；地址保留稿件 ID，刷新仍打开同一篇。返回列表或切换稿件前先完成保存，保存失败保留当前编辑。无效或跨账号稿件地址不会回退打开其他稿件。

生成作为持久化后台任务运行。新建时先保存原稿，随即进入独立的生成页面，只显示本次选题和进度；提交中、读取中或失败时均不回显旧稿。刷新可恢复对应任务，在生成页等待完成后打开本次新稿；返回列表或手动打开其他草稿后，后台完成的任务不会抢走页面，仍可从列表的任务入口查看进度和结果。成功不常驻完成横幅，任务及草稿记录仍保留。失败时保留收藏并显示原因。重复提交同一请求复用任务；服务重启前未完成的任务会标记失败，不自动再次调用 AI。链接读取失败时不会假装取得正文或截图，可重读或手动补充资料后重试。

草稿只编辑实际发布的标题、正文与话题，右侧管理这篇稿件的配图。资料核对备注不出现在编辑器；必要核对项放在预览排期中，确认后按稿件版本与产品资料版本记录。正文、图片或产品资料变化后需要重新核对，新复制的稿件也不会继承核对结果。AI 图文稿保存后自动接续三张配图：封面、正文要点和与本篇主题相关的补充页；文案先可编辑，配图独立排队。也可单独重新生成封面。自动读取已保存文案、产品事实和真实产品图，无需另选模式、尺寸或写完整提示词。AI 修改、上传替换、素材选图、裁剪和排序均在原稿内完成；不展示全局测试图片任务墙。停止输入900ms后自动保存；版本冲突会提示处理，避免旧页面覆盖较新的修改。进入预览排期前会等待保存完成；“确认并排期”由服务端在同一次更新中核对草稿归属账号和版本、运行内容及图片检查，再批准并创建排期。检查不通过时不会部分批准或排期。AI 修改先保存当前编辑，再根据修改要求创建一篇新稿，不覆盖原稿。

## AI 连接与当前状态

已有连接配置保存在忽略的 `runtime/connections.json`（0600），删除设置页面不会删除连接配置。公开状态与 GET 接口不回传密钥；后台接口在更换服务地址时要求新密钥。协议支持 Chat Completions 或 Responses；环境变量 `REDPILOT_AI_WIRE_API` 接受 `chat`、`responses`，旧配置默认 `chat`。两种协议都发送 `store:false`；这只是请求参数，不代表第三方服务的实际留存承诺。

飞书私信连接位于左下账号菜单的“飞书提醒”，填写公司自建应用的 App ID、App Secret 和个人飞书邮箱或 Open ID，再点击“保存并发送测试消息”。应用需已开启机器人和发消息权限，且接收人在应用可用范围内。凭据仅保存到忽略的 `runtime/feishu-notifications.json`（0600），访问令牌只在内存缓存；接口不回传密钥。没有配置或发送失败时保留待提醒事件，后续按退避策略重试，不把尝试发送当作已送达。每次掉线使用稳定消息标识，重试复用标识。飞书接口使用官方[应用认证](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)和[发送消息](https://open.feishu.cn/document/server-docs/im-v1/message/create)。

连接探针只发送固定 JSON 要求和测试图片，不发送产品资料；“已配置”不等于“已验证”。探针和实际文字分析、创作及历史讨论兼容接口共用请求与解析逻辑，Responses 支持完整 JSON 与流式完成结果，拒绝被截断、拒答、失败或未完成的输出。协议切换会重置验证状态；不会自动尝试其他模型、服务地址或密钥。

文字分析与图片生成分别需要有效的服务配置。连接探针未通过时不显示已验证；文字接口测试成功不代表图片生成接口可用，实际任务结果仍需分别验证。

## 热点与日报

热点页并列显示小红书、抖音、B站、微博、知乎、百度和头条，保留各自榜名、官方序号、原链接与采集时间，每榜最多 30 条。平台榜单的统计口径不同，不合成为一个“全网热度”。账号匹配区根据账号名称、定位备注和产品资料进行关键词与分类规则排序，显示 0 至 10 的匹配分和理由；这个分数不是平台热度、曝光预测或 AI 评分。

采集串行执行，只使用自己的后台浏览器标签，结束后关闭。页面外壳加载完成后，继续在8秒预算内等待榜单出现；小红书旧版搜索框会自动展开一次；没有榜单时再读取创作中心，话题页面等待最多15秒。经典话题与热搜使用不同类型，话题不计入“全网热度”的榜位统计；分类切换只在选中状态和内容均更新后采纳，所有刷新仍由每日09:00任务统一执行。登录、验证、页面变动和网络状况会影响可用平台，不保证七站或全网始终可读。页面显示可用来源数量，分别标明需登录、需验证、浏览器未连接、网络异常、未找到榜单或加载未完成；已读取的 DOM 窗口显示“已读取”。刷新失败时保留上次真实快照及原采集时间，并明确标为旧数据；没有真实快照时保持空榜。DOM结果只代表当前可读窗口，不声称覆盖完整榜单或文章全文。

全平台热榜默认每天北京时间 09:00 自动刷新，与账号发帖、日报开关分开。服务运行时每天执行一次；当天 09:00 后启动会补执行当天任务，不补历日任务。正在进行的手动或日报刷新会复用，失败保留原快照，可手动重试。定时状态保存在本机数据中，重启不会重复执行同一天已触发的任务；需要本机服务持续运行，服务器部署后由服务器执行。

今日工作台合并运营概况和日报，不再设置独立日报导航。每个启用账号的日报固定在每日 09:00（Asia/Shanghai）生成，没有额外开关或时间设置，与发帖设置分开。只有本机服务运行时才调度，每个账号本地日期一次，可手动生成并查看历史；不补往日自动任务。多个账号可复用近期榜单刷新结果。日报使用已保存的数据与本地规则，首页仅展示今日排期、已核验发布、待核对草稿三个核心指标；发布和生成异常有待处理项时显示。资料同步完整性、快照处理说明和例行产品资料核对不出现在首页。待办只展示标题、完成勾选和处理入口；核对数量、展开说明、资料缺口和优先级标记不出现在待办中，已保存的历史日报同样适用。发现保留来源与创作入口。它不编造曝光、评论、转化或发布成绩。热点发现只采用与日报日期一致、未标为旧数据的快照；缺少该日榜单时使用本地资料并说明缺口。后台快照保存账号、时区和统计时间；已有过去日期日报保留历史快照，没有快照时不把当前状态伪装成历史。同日更新保留已完成标记及已解决的完成条目。

热点和日报条目可直接生成草稿或存入统一收藏，不再要求进入讨论。历史讨论的来源、需求和真实消息继续保留；兼容接口仍按账号隔离，来源中的指令只作不可信资料。榜单标题与链接不表示已阅读对应文章全文；创作只依据实际取得的内容，不能声称读过未读取的正文，输出仍需核对。

热点快照、账号匹配、选题、日报、讨论和来源记录保存在忽略的 `runtime/`，不上传公开代码仓库。

## 飞书资料同步

在“产品资料”的“资料来源”中维护链接，点击旁边的“飞书同步”即可保存当前来源并刷新正文；只保存产品资料或打开页面不会开始同步。可添加目录以发现新文档。旧的独立飞书来源会并入资料来源，旧自动同步配置不再生效。仅在本机服务和已连接 Chrome 可用时读取，不需要文字 AI。当前不使用飞书服务端开放平台凭据；迁移服务器后需重新接入可用读取方式。

原文按地址和内容哈希更新。无正文变化时不提升产品版本；新增或变化使未发布草稿需要重新核对。已有完整正文不会被本次不完整窗口覆盖。手工维护的产品名称、阶段、能力、条件和限制始终保留；不会把原文机械改写为已验证功能。已移除来源的历史快照保留查看，创作不再引用；同时变更来源会使旧草稿需要重新核对。

AI 创作、参考分析和历史讨论兼容接口会使用当前来源的同步原文（总正文最多24000字符、单篇最多8000字符，注明旧/不完整/上下文截断）。手工限制优先，资料内的指令不可信；矛盾与未验证内容必须待核对。本地模板仍只依据手工整理的产品事实。原文、配置和任务只保存于忽略的 `runtime/`，不上传公开仓库。并发同步合并一个任务，读取在状态锁外执行；重启中断任务会标失败，下个周期再试，不立即重放。

## 关注博主

在“灵感收集 → 关注博主”管理平台内的参考博主列表，可填写主页链接或小红书号。小红书号通过站内“用户”搜索，最多核对 4 个候选的可见账号资料，完全匹配后才确定身份；不能确认时保留待确认状态，可改用主页链接。

添加后进行首次同步，最多新建 10 篇收藏。每次只扫描主页当前加载的近期窗口，最多 50 条，适量向下滚动，不代表全量历史。首次窗口中超出导入额度的旧笔记建立基线，后续不作为新内容批量补录。之后每天自动同步一次，每次最多新增 20 篇尚未见过的笔记；手动同步也按每次 20 篇限额，额外手动同步不计入每日自动执行次数。“新”指新发现的笔记，不代表当天发表。

置顶单独标记，去重使用笔记 ID；同一笔记的普通链接和带参数的主页内链接合并为一条收藏，保留博主来源和实际笔记链接。读取会补齐正文和主图，用户手填的字段与截图继续保留。暂停会停止每日同步，仍可手动同步；归档保留已收藏内容和历史记录。

每日同步仅在 RedPilot 服务运行、电脑未休眠且 Chrome 读取桥已连接时执行，读取还需小红书登录可用。服务重新启动后只处理当天到时且尚未运行的同步，不补往日任务。登录失效或页面要求验证时记录原因，处理后手动同步；不会自动处理验证码。

自动拆解需为该博主单独开启，并由后台配置有效的 AI 服务。模型会收到已读取的该篇图文与产品资料，分析选题、标题、结构、可见视觉和适配点。读取和同步本身不需要 AI 密钥；未配置、来源未就绪或 AI 失败时，来源继续保留，可在配置完成后处理待拆解内容。相同来源和产品版本的成功拆解会复用；资料在调用期间变化时不会覆盖成旧结果。主页摘要不当作笔记全文，视频只分析可见标题与描述，不自动转录；输出仍需人工核对。

博主记录、实际来源链接、读取快照、参考图片和拆解历史都保存在被 Git 忽略的 `runtime/`，不上传公开 GitHub 仓库。

## 图片工作台配置

在“创作工作台”打开稿件，右侧直接生成、修改或替换本篇配图。默认生成封面、正文要点、主题补充三张竖图（1024 × 1536），也可只生成封面。自动选择真实产品图作为外观参考，结合当前标题、正文和产品事实；同次文字创作会从已提供的参考截图提炼视觉方向，配图只借鉴排版、层级、配色与节奏，保留自有产品身份。文案和配图按本篇主题组织，不固定附带使用条件、未验证承诺、开发状态或免责声明清单；后台资料只作事实依据。无参考截图时使用原创方案；资料不足时不添加不存在的硬件或功能。单图修改保持原位置，裁剪默认保留原图比例，完成后原位应用；上传与素材库选图也不必跳转页面。

`POST /api/drafts/:id/images` 捕获稿件版本、账号、正文与原配图，按顺序生成并在整组结束时回填成功图片。同一请求键复用任务；失败图片可单独重试。生成期间修改文案、账号或图片会停止自动回填，保留结果供手动采用，避免覆盖新编辑。任务只显示在所属稿件；切换稿件、输入文案和图片替换与自动保存协调执行。自动创作的图片队列可跨稿件排队，整套完成前不自动发布，部分失败也不使用原图代替。自动发布要求三张成品互不重复、封面和内页全部回填、账号与版本仍有效，并通过原有事实及图片检查；服务直接回传参考图或同批重复图会判定失败。服务重启不自动重复调用图片服务。

模型渲染产生几何预览，只能作为后续制作参考，不能直接发布；测试图及其衍生图片也会被发布检查拦截。普通用户上传的产品照片与渲染成图仍可使用。图片服务会结合用户要求加入构图、光影、材质、文字排版与产品外观保真约束，保留原始要求供查看。AI 成品通过 `metadata.usage: publication` 标记；带 `draftId` 或 `reusable: false` 的专属封面不会自动用于其他新稿。

在本机 `.env` 中配置后重启服务：

```dotenv
REDPILOT_IMAGE_API_KEY=
REDPILOT_IMAGE_BASE_URL=https://api.openai.com/v1
REDPILOT_IMAGE_MODEL=gpt-image-2.5-sunburst
```

`REDPILOT_IMAGE_API_KEY` 留空时优先使用 `OPENAI_API_KEY`；两者均未配置时，只有规范化后的图片服务地址与主 AI 的公网 HTTPS 服务地址完全一致，才复用 `REDPILOT_AI_KEY`。模型仍使用独立的图片模型配置，主 AI 密钥不会发送到另一个图片服务。密钥只留在服务端；状态接口仅返回是否已配置与模型名称，配置完成不代表已经验证真实生图。默认模型依据当前 [OpenAI 图片指南](https://developers.openai.com/api/docs/guides/image-generation) 与 [编辑 API](https://developers.openai.com/api/reference/resources/images/methods/edit) 选择，可自行改为兼容图片 API 的模型。

纯文字生成调用 `/images/generations`；参考图编辑调用 `/images/edits`，仅发送当前选中的 1 至 4 张 PNG、JPEG 或 WebP 图片及本次要求，不会把 SVG、宣传册或模型文件直接发送给图片服务。提示词最多 4000 字符，支持 1024 × 1024、1024 × 1536、1536 × 1024，每个底层请求生成一张图，稿件整组通过顺序队列生成三张。请求有 3 分钟超时，返回图片上限 20MB，校验编码和图片格式；只接收返回的 `b64_json`，不下载服务返回的远程 URL。自定义服务需要支持这两类端点和 base64 结果。未配置密钥时不发起请求；自动化测试使用模拟结果。已在本机通过稿件入口实测单张封面生成与自动回填，结果仅保存在本机 runtime 中。

## 平台登录

未登录访问工作台会跳转登录页；所有业务接口、图片、PDF、模型、上传截图和参考资料均要求有效会话。登录页、登录脚本、公共CSS/字体和只读会话状态为公开入口。没有账号自助注册或远程初始化功能，未完成本机配置时也无法匿名进入。

账号配置保存在忽略的 `runtime/auth.json`，密码仅保留随机盐与 scrypt 哈希，文件权限0600；真实邮箱密码不会写入前端、示例或公开仓库。登录页默认勾选“记住登录 30 天”。Cookie 为随机会话标识，设置 HttpOnly、SameSite=Strict；勾选后在同一浏览器保留30天，服务重启后仍有效，期限从本次登录起计算，不因访问自动延长。服务端只在忽略的 `runtime/sessions.json`（0600）保存会话标识的哈希、期限和凭据指纹，不保存明文密码或可直接登录的 Cookie；浏览器 localStorage 不保存密码。取消勾选时保留原来的8小时临时会话，服务重启后失效。主动退出会立即撤销当前浏览器会话；重新配置登录凭据后，旧的记住登录状态在重启时失效。登录有同源检查和每IP最近15分钟5次尝试限制，成功登录会清除失败记录。

要重设账号，在本机重新运行 `npm run auth:configure` 并重启服务。自动化配置可使用 `node scripts/configure-auth.mjs --json-stdin` 从隐藏的标准输入接收 `{email,password}`；不要把密码写进命令行参数。平台登录账号只用于本工作台，和小红书账号登录分别管理。

认证实现使用 [Node.js Crypto](https://nodejs.org/api/crypto.html)；Cookie 属性参照 [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。

## 产品素材与3D渲染

进入“产品资料 → 素材库”查看和上传素材。“宣传册”后提供“生成”分类，已有和后续 AI 配图、模型渲染、裁剪结果按来源自动归入；“产品图片”仅展示原始图片，“全部”仍可查看所有素材。分类不改变文件类型和图片用途。图片、SVG 图标与 PDF 保存在本机 `runtime/product-assets/files/`；PDF 提取文字和首页预览（系统需有 Poppler 的 pdfinfo、pdftotext、pdftoppm，缺失时仍保存原件）。文件内容只作为资料，不执行其中指令，也不会把宣传册里的承诺自动写进产品事实。

3D 模型支持在页面上传单个 STEP/STP、STL、GLB、OBJ 或 BLEND 文件，单文件最多 1GB。上传采用二进制流，校验后保存到本机 `runtime/product-assets/files/`，之后不依赖原文件路径。暂不支持 `.gltf` 上传或自动收集模型的外部依赖。当前仅 STEP/STP 可以按标准、正面、侧角渲染产品图，其余格式保存为模型素材，可下载，暂不能直接渲染。

已有的本地模型引用继续保留，仍只记录绝对路径、摘要和说明；源文件移动或改变后会提示重新关联，不会自动复制大文件。如果主动上传的文件与已有引用的 SHA-256 相同，会将原素材转为本机托管，保留素材 ID 与已有预览，之后不再依赖旧路径。上传不会修改或删除用户原文件。

渲染任务完成后将 PNG 入库，失败原因会保留。STEP 首次转换生成可复用网格缓存，后续渲染更快；缓存不额外复制 STEP 原件，同一模型不会并发重复渲染。

CAD 渲染可选依赖见 `requirements-render.txt`，当前工作站已安装，无需重复安装。可指定 `REDPILOT_PYTHON` 选择 Python 环境：

```bash
python3 app/render_product.py --probe
python3 app/render_product.py --model /absolute/path/product.step --output /absolute/path/product.png --preset studio --cache-dir /absolute/path/cache
```

生成图使用源模型几何与示意材质，不能代替实机或功能测试。图文稿可选择原图、裁切保存图或 AI 成品；CAD 渲染图仅作几何参考；配置文字 AI 后，选中的产品图片会连同参考一起输入模型。AI 新稿将所选产品图保存在 `imageSourceAssetIds`，不会直接作为成品挂到 `productAssetIds`。只有真实图片任务完成后才回填成品；图片服务未连接或生成失败时保留文案，明确显示待生成状态。未配置 AI 的本地模板仍可按手动选择直接使用产品照片；切回图文不会自动塞入素材。图文审核及排期至少需要一张 kind=image 主图，SVG 图标仅作来源。文字稿不带自有图片。发布桥收到的 `post.images` 与预览及 ZIP 主图一致，按选择顺序排列，无需再次合成文字卡。辅助分镜与固定栏目不显示、不生成，也不放入导出包；旧稿中已有的值仅作兼容存储，发布检查只检查实际标题、正文及必需事实和图片。

所有真实素材、上传模型、模型引用路径、渲染缓存和生成图片均保留在忽略的 `runtime/` 中，不上传公开代码仓库。备份整个 `runtime/` 会包含已上传模型；仍为本地引用的模型需要另外备份原文件，迁移后重新关联新路径。

## 内置 Chrome 图文发布的边界

“连接小红书 / 检查登录”调用 `POST /api/accounts/:id/connect-publisher`。已实网只读核验创作者中心账号标识、目标主页标识、公开笔记作者及标题组成的严格身份链，并检查图文入口；文档不记录具体账号身份。`ready` 只表示这层登录身份与入口核对，首篇仍显示“首篇待验证”。

图文发布代码已实现，每次发布及最终提交前再次核对身份。浏览器工作在状态锁外的 `nativeQueue` 串行执行，幂等记录保存在 `runtime/xhs-publisher.json`（0600）。结果未知只允许 verify，不重新提交；只有记录证明未尝试提交时，才可由用户显式重试。用户核对并排期的首篇经真实笔记核验后，才设置 `publishVerified` 并允许该账号自动发布。

当前尚未实测真实图片上传、表单填充、点击发布或发布后核验，未执行真实发布测试。原生文字模板入口虽已检测到，当前仍为 `unsupported`；不将入口存在当作文字发布已验证。外部桥的文字流程仍按 v3 能力开关单独接通与验证。

## 多账号

在左下角账号菜单直接点击“添加账号”，在弹窗填写昵称、类型、小红书号、主页和备注；保存后切换到新账号。编辑当前账号通过“账号资料”弹窗完成，登录检查、启停与归档保留在弹窗中，“每日发布”从菜单直接打开。选择另一个账号后，整个平台使用该账号的独立资料。当前选择保存在本浏览器，刷新后恢复；失效的账号选择自动退回默认账号。切换前保存草稿，未保存的产品资料会提示处理。

产品事实、来源、素材、飞书文档、收藏、关注博主、草稿、图片任务、排期和日报分别保存，不自动复制到新账号。新账号从空资料库开始。公共平台热榜快照共用，但“适合我的账号”根据当前账号定位和产品资料重新匹配。异步任务保留发起账号的上下文，切换页面不会改变其保存位置。共享的 AI 服务配置与平台登录凭据仍属于整个工具。

服务端通过 `X-RedPilot-Account` 请求头选择工作区，图片链接通过 `workspace` 查询参数固定归属；两者冲突时拒绝请求。草稿或素材 ID 只在当前工作区查找，不能用其他账号的 ID 修改资料或排期。私有数据存入忽略的 `runtime/state.json` 中的 `accountWorkspaces`，接口只返回当前账号资料。后台按账号逐一调度，账号列表和公共热榜保存在根级。

`bridgeAccountId` 是所选发布通道的实际账号映射；仅添加记录或填写 ID 不等于已经登录。内置驱动当前复用单个 Chrome 登录态，连接与提交时严格比对所选账号，不一致即阻塞；尚未实现每个小号独立 Cookie/profile 或自动切换登录。外部发布桥仍须自行按账号隔离会话。本工作台不收集小红书密码或读取 Cookie。

旧版本升级会保留现有账号、草稿、任务和每日设置。有账号归属的记录进入对应工作区；原来的公共产品资料、飞书来源和无归属收藏进入原默认账号。旧稿实际引用的素材和参考保留独立副本，新账号不继承这些内容。`REDPILOT_ACCOUNT_ID` 只用于最早单账号数据的发布映射迁移，新号必须单独配置，未配置的新号不会回退到官方号发布。

暂停账号会阻止新的发布；历史结果仍可核对。归档前需要取消或核对未完成任务，页面会切换至另一个账号并将其设为默认账号。仅有一个账号时不提供归档。归档保留数据。存在排期或提交历史的账号不允许换成另一个外部发布 ID，以免旧任务串号。

## 数据与运行方式

- 默认仅监听 `127.0.0.1`，只供本机单人使用，平台登录为单用户，和管理的多个小红书账号分开。不要直接反向代理成公网服务。
- `runtime/state.json` 保存资料、收藏、博主来源与同步/拆解任务、热点快照、选题、日报、讨论、飞书原文和同步任务、草稿、排期和最近 200 条运行记录；`runtime/uploads/` 保存截图与读取到的参考图片，`runtime/product-assets/` 保存产品素材、PDF预览、网格缓存和渲染结果。
- `runtime/connections.json` 保存私密服务配置，`runtime/xhs-publisher.json` 保存内置驱动幂等与提交证明，权限均为0600。
- 原子写入、串行更新与进程锁保护本机数据。运行一个实例；启动时会把中断的发布标记为待核对。
- 完整 `runtime/` 备份包含图片、内容、私密配置与发布幂等记录，应私密保存。页面 JSON 快照不含密钥文件或图片，当前无页面恢复入口。
- `.env`、运行数据、Cookie、登录态、密钥均忽略，不随公开代码上传。

## 检查

```bash
npm run check
npm test
```

接口测试覆盖持久化、输入检查、去重、版本失效、排期竞争、每日运行、AI 请求格式、发布幂等与结果核对，以及素材导入/文件校验/路径隔离/异步模型渲染、登录保护/会话失效/频控。内容回归覆盖旧分镜不阻碍核对、真实标题正文仍需依据、主图校验和新稿不再生成分镜或固定栏目。会改变平台内容的发布步骤使用测试替身；实际只读身份链及文字 AI 草稿生成已核验；真实图片上传/填充/点击发布与首篇发布结果仍未验证。
